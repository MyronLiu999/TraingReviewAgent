# 学习资料 / Study material

把你的交易资料放在这个文件夹里（支持 `.md`、`.txt`、`.pdf`）。
每次复盘时，机器人会读取这里的 .md / .txt 笔记（作为 [USER NOTE]，Brooks 原典定义仍然优先）。Brooks 知识库可用时，这里的原书 PDF 会被跳过。
