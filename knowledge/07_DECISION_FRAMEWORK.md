# 07 复盘决策框架 Decision Framework

Provenance: general_knowledge（AI 助手整理，未对照原书核实） · Confidence: 中

复盘一张图时，必须**按顺序**执行以下步骤。前一步的结论决定后一步哪些规则可用：
形态规则只有在其 Required Context 满足时才能引用。

## DF-1 读图与可靠性
- 识别品种、周期、可见的 K 线数量、是否有均线（通常是 20 EMA）、价格轴是否可见。
- 看不清的区域（K 线太密、被遮挡）要在分析中说明，不得臆测具体某根 K 线。

## DF-2 划分市场阶段（从左到右）
- 把图分成若干段：强趋势（多/空）、通道、交易区间（TR）、窄幅区间（TTR）。规则见 PA-TRD-001、PA-TR-001、PA-TTR-001、PA-CH-001。
- 每段判断 **Always In** 方向（PA-CTX-001），以及在哪里、因什么发生翻转（通常是强突破 + 跟进，PA-BO-001）。

## DF-3 定位关键事件
- 突破与跟进（PA-BO-001）、突破回调（PA-BO-002）、尖峰与通道（PA-SC-001）
- 高潮（PA-CLX-001）、楔形（PA-WDG-001）、双顶/双底（PA-DT-001）、主要趋势反转（PA-MTR-001）
- 失败突破（PA-FBO-001）、末端旗形（PA-FF-001）、量度目标（PA-MM-001）

## DF-4 找出当时的交易机会（setups）
- 顺势：H1/H2（PA-H-001/002）、L1/L2（PA-L-001）、均线回调、突破回调。
- 逆势：只有在 PA-MTR-001 或 PA-CLX-001 等条件满足、并且有强信号 K 线时才算合格（TD-001）。
- 对每个机会评估：信号 K 线质量（PA-BAR-001）、入场方式、止损（TD-003）、目标（TD-004）、交易者方程（TD-002）。

## DF-5 指出不该做的交易
- 引用 TD-005：TTR 中间、区间中部追单、强趋势里的第一次逆势信号、弱信号 K 线等。
- 如果用户提供了自己的交易，逐项对照：背景是否支持、信号是否合格、止损和目标是否合理。

## DF-6 当前状态与下一步
- 当前 Always In 方向、所处阶段（趋势 / 回调 / 区间 / 可能反转）。
- 列出多空双方各自需要看到的确认信号（例如：强阳线收在高点并有跟进 → 多方确认）。
- 给出概率倾向时只能用"可能 / 偏向 / 50-50"这类表述，不得编造具体胜率。

## DF-7 诚实原则
- 区分"图上能直接看到的事实"和"推断"。
- 引用规则时，必须是该规则的 Required Context 已满足；部分满足要说明缺少什么。
- 这是复盘与教学，不是交易建议。
